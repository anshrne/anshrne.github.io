World Map Explorer is an interactive web application designed to help users discover countries instantly. It combines live country data, a smooth map interface, and a user-friendly design to make global exploration easy and fun.

Global Discovery

Instantly search and explore any country in the world. Get quick access to essential geographic and cultural information in one place.

Interactive Map Experience

Navigate a smooth, zoomable world map powered by Leaflet. Visually explore locations with precise markers and real-time positioning.

Live Country Data

View up-to-date information including population, capital city, languages spoken, region, and currency details instantly after searching.

Built with REST Countries API + Leaflet Maps
